# Brijesh Soni — Technical PM Portfolio

Personal portfolio site for **Brijesh Soni** (Sr. Technical Product Manager, AI/ML · Cloud · SaaS · FinTech).

Live site: [github.com/brijs001/portfolio-2026](https://github.com/brijs001/portfolio-2026)

## What's included

- **4 case studies** from Bank of America and Verisk Analytics, each following a 4-section structure: the problem, the customers, the solution under his ownership, and the results — measured, not claimed.
- **Dual-audience framing** — appealing to both PM recruiters and consulting/Upwork leads.
- **Light and dark mode**, mobile-responsive, accessibility-minded.

## Tech

Pure static HTML/CSS/JS. No build step. Host on any static host.

## Deploy options

- **GitHub Pages** (free, public repos): Settings → Pages → Deploy from branch → `master` / `root`.
- **Vercel** (note: Vercel Hobby tier prohibits commercial use — including portfolio sites advertising paid consulting services, per their own [terms](https://vercel.com/docs/limits#hobby).
- **Netlify** (free tier permits commercial use).
- **Cloudflare Pages** (free tier permits commercial use).

## Local preview

```bash
git clone https://github.com/brijs001/portfolio-2026.git
```
